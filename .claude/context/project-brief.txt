# KALAHARI - Project Brief
# Imported into CLAUDE.md (main session and subagents). Keep it short and in sync with the code.

## Project
- Name: Kalahari (Writer's IDE), version 0.3.x-alpha
- Type: Desktop Application
- Stack: C++20 + Qt6 6.4+ (builds use 6.9), CMake + vcpkg, Python plugins (pybind11), Catch2 v3 tests
- Phase: Phase 1 - Core Editor (in progress); see ROADMAP.md

## Build & Test
- Windows: scripts/build_windows.bat Debug   -> tests: ./build-windows/bin/kalahari-tests.exe
- Linux:   scripts/build_linux.sh             -> tests: ./build-linux/bin/kalahari-tests
- macOS:   scripts/build_macos.sh
- NEVER: cmake directly, WSL for Windows builds

## Source Structure
include/kalahari/   (headers)     src/   (sources, same layout)
├── core/           # business logic, singletons, plugins, project/database
│   └── utils/      # icon downloader, SVG converter
├── editor/         # BookEditor: KML document model, layout, rendering, services
├── gui/            # MainWindow, coordinators, registries, settings dialog
│   ├── dialogs/
│   ├── panels/     # editor, navigator, log, properties, search, tags, ...
│   ├── widgets/
│   └── utils/      # layout_utils.h (clearLayout)
src/bindings/       # pybind11 Python bindings
tests/              # core/, editor/, gui/, benchmarks/ (Catch2)

## MainWindow Architecture
MainWindow orchestrates 7 coordinators:
- IconRegistrar, CommandRegistrar, DockCoordinator
- DocumentCoordinator, NavigatorCoordinator
- DiagnosticController, SettingsCoordinator

## Singletons (CORRECT API)
- core::ArtProvider::getInstance()      # icons, colors, actions
- core::SettingsManager::getInstance()  # configuration
- core::ThemeManager::getInstance()     # themes, palettes
- core::IconRegistry::getInstance()     # icon registry (internal)
- core::Logger::getInstance()           # logging
- core::TrustedKeys::getInstance()      # plugin publisher keys
- gui::CommandRegistry::getInstance()   # command registry (thread-safe)

## MANDATORY Patterns (CORRECT API)

### Icons
core::ArtProvider::getInstance().getIcon("cmd_id")
core::ArtProvider::getInstance().createAction("cmd_id", tr("Text"), parent)

### Icon Colors
core::ArtProvider::getInstance().getPrimaryColor()
core::ArtProvider::getInstance().getSecondaryColor()
core::ArtProvider::getInstance().setPrimaryColor(QColor("#hex"))

### Configuration
core::SettingsManager::getInstance().get<int>("editor.fontSize", 12)
core::SettingsManager::getInstance().set<std::string>("appearance.iconTheme", "twotone")

### Themes
core::ThemeManager::getInstance().getCurrentTheme()
// Access: theme.colors.primary, theme.colors.secondary, theme.palette

### UI Strings
tr("User visible text")

### Logging
core::Logger::getInstance().info("Message: {}", value)

## NEVER Use
- QIcon("path/to/icon.svg")     # Use ArtProvider
- QColor(255, 0, 0) in UI code  # Use ArtProvider/ThemeManager colors (theme defaults are the exception)
- "Hardcoded string" in UI      # Use tr()
- SettingsManager getValue()/setValue()  # Do NOT exist - use get<T>()/set<T>()
- Theme::instance()             # Does NOT exist!
- ArtProvider::instance()       # Wrong method name!

## Naming Conventions

## Task Management

## MCP Servers & Semantic Tools
- Context7: external library documentation (Qt6, etc.)
- Serena: semantic C++ navigation (find_symbol, find_referencing_symbols, symbol-level edits)
- Both are configured per machine in a git-ignored .mcp.json (template: .mcp.json.example).
  If they are unavailable, fall back to Grep/Glob/Read.
- Native LSP tool (clangd): not functional on the Windows setup; use Serena or Grep/Glob/Read.
